Implementation status & limitations ↗

Install on Android

  1. Download the signed APK from the latest GitHub Release.
  2. Open it from Files. If prompted, allow installation from that app in Android Settings.
  3. Install Vynox, then turn that permission back off. Future updates must use the same signing key.

Only install APKs from a source you trust. SHA-256 checksums accompany releases. Keep copies of important .vnx projects.
